#### 用户与组的关系, 主组(Primary Group)与附加组(Supplementary Group)
``` shell
useradd -u 4000 -g 1000 -G xusx -s /sbin/nologin -d /tmp/aaa xusx
  -u 4000	                指定用户的 UID(用户ID)	                将用户xusx的UID设置为4000。
  -g 1000	                指定用户的主组(GID)	                    将用户xusx的主组设置为GID为1000的组。
  -G xusx	                指定用户的附加组(Supplementary Group)	将用户xusx添加到名为xusx的组中。
  -s /sbin/nologin          指定用户的登录 Shell	                将用户xusx的登录Shell设置为/sbin/nologin, 意味着该用户无法交互式登录系统。
  -d /tmp/aaa	            指定用户的家目录	                    将用户xusx的家目录设置为 /tmp/aaa。
  xusx                	    要创建的用户名	                        新用户的用户名为 xusx。
usermod -G root -s /bin/bash xusx
	-u  uid
	-g  gid主组
	-G  root附加组
	-d  家目录
	-s  用户登录shell
	-o  可以手动指定一个已被其他用户占用的 UID

# 删除用户
userdel -r xusx
```

#### 用户的登录
``` shell
su xusx       非登录用户
	加载文件顺序
		/home/xusx/.bashrc --->       用户私有配置文件, 定义BASH SHELL功能
		/etc/bashrc --->              全局配置文件, 定义BASH SHELL功能

su - xusx     登录用户.
	加载文件顺序
		/etc/profile --->              全局配置文件, 只有用户登录的时候才会加载, 仅加载一次
		/etc/bashrc --->               全局配置文件, 定义 BASH SHELL
		/home/xusx/.bash_profile --->  用户私有配置文件, 环境变量
		/home/xusx/.bashrc --->        用户私有配置文件, 定义BASH SHELL功能
```

#### sudo以管理员权限执行命令
``` shell
# 编辑sudo文件
visudo
# 检查语法
visudo -c

# sudo提权, 且无需输入密码:
xusx ALL=(ALL)       NOPASSWD: ALL

# 允许用户xusx执行任何命令
xusx   ALL=(ALL)       ALL
# 允许用户xusx权限执行systemctl和journalctl命令
xusx   ALL=(root)      /usr/bin/systemctl, /usr/bin/journalctl
# 不允许用户xusx执行passwd命令修改root密码
xusx   ALL=(ALL)       NOPASSWD: /usr/bin/passwd,! /usr/bin/passwd root

sudo用户行为审计:
Defaults logfile=/var/log/sudo.log

sudo定义别名:
```
